## 场景类别在本项目的适配说明
本项目为**单机本地 RL 工具**，无多用户/在线服务，因此对两类场景做如下领域映射：
- **权限问题** → **文件系统/磁盘权限**（检查点目录不可写、配置文件无读权限、磁盘满、只读路径）。
- **网络问题** → **依赖/环境/端口**（首次依赖安装、离线环境、TensorBoard 端口占用、Docker 镜像拉取）。

## 用例详情（关键示例）

### TC-002 — 一行四个相同方块向左合并
- **关联 Story**：US-01 / AC-2
- **场景类别**：正常流程
- **前置条件**：构造棋盘某行为 `[2,2,2,2]`
- **步骤**：
  1. 调用向左移动逻辑
- **预期结果**：该行变为 `[4,4,0,0]`，且每个方块在本次移动中只参与一次合并；本步得分 +8。

### TC-023 — Apple M2 上使用 MPS 设备训练
- **关联 Story**：US-05 / AC-4
- **场景类别**：边界条件（硬件）
- **前置条件**：运行于 Apple M2，配置 `device=mps`
- **步骤**：
  1. 以 quick 配置启动训练
- **预期结果**：训练正常进行，全程无 CUDA 依赖；若 MPS 不可用则可回退 CPU。

### TC-039 — 5 分钟可复现启动
- **关联 Story**：US-09 / AC-1
- **场景类别**：正常流程
- **前置条件**：干净的 Python 3.10.11 环境
- **步骤**：
  1. 按 README 安装固定版本依赖
  2. 执行一键训练命令（quick 配置）
- **预期结果**：从安装到开始训练总耗时 ≤ 5 分钟，无报错。

### TC-048 — 训练后 Agent 智能性达标
- **关联 Story**：US-11 / AC-1, AC-3
- **场景类别**：正常流程
- **前置条件**：full 训练得到的 best 检查点
- **步骤**：
  1. 运行评估脚本跑 N 局（如 N=100）
  2. 统计 max-tile 分布
- **预期结果**：输出 max-tile 中位数/均值/最大；**中位数 ≥ 512** 判定达标（S2）。
